# Backend

API бо FastAPI сохта шудааст. `app.py` нуқтаи воридшавӣ ва ҳоло файли асосии тамоми backend мебошад.

## Тартиби хондани `app.py`

1. Танзими SQLite ва сохтани `app`-и FastAPI.
2. Моделҳои Pydantic барои воридшавӣ, корбар, сертификат, хабар ва муҳтавои сайт.
3. Функсияҳои базаи додаҳо, сохтани ҷадвалҳо, иҷозат ва рақамгузории сертификатҳо.
4. Роҳҳои `/api/health`, `/api/login`, `/api/register` ва `/api/me`.
5. Роҳҳои `/api/certificates` барои феҳрист ва идоракунии сертификатҳо.
6. Роҳҳои `/api/news` ва `/api/site-content` барои хабарҳо ва муҳтавои пажӯҳишгоҳ.
7. Роҳҳои `/api/dashboard` ва `/api/audit` танҳо барои маъмур дастрасанд ва барои панели маъмурӣ ва сабти амалиёт истифода мешаванд.
8. Роҳи `/api/media` барои боркунии файлҳои администратор; `/media/` онҳоро барои намоиш дастрас мекунад.
9. Роҳи `/api/news/{id}/views` шумораи хонандагони беназири беномро барои ҳар хабар нигоҳ медорад.

`registry.db` базаи маҳаллии SQLite аст. Вобастагиҳои Python дар `requirements.txt` нигоҳ дошта мешаванд.
Файлҳои медиавӣ берун аз база, дар `uploads/`, нигоҳ дошта мешаванд; ҳангоми оғоз ҷузвдон худкор сохта мешавад. Базаи SQLite дар `registry.db` аст; барои тағйир додани ҷойи он `REGISTRY_DB_PATH`-ро истифода баред. Маълумоти шахсии довталабонро дар феҳристи сертификатҳои оммавӣ барнагардонед.

## Амният ва истеҳсол

- Паролҳои нав бо scrypt ва salt-и тасодуфии инфиродӣ нигоҳ дошта мешаванд. Паролҳои кӯҳнаи PBKDF2 ҳангоми воридшавии бомуваффақият ба scrypt гузаронида мешаванд; пароли бақайдгирии нав бояд на кам аз 12 аломат бошад.
- Ҷаласаҳо дар SQLite танҳо бо hash-и токен нигоҳ дошта мешаванд; браузер токенро танҳо дар кукии `HttpOnly`, `Secure` (истеҳсол), `SameSite` нигоҳ медорад. Ҳангоми навсозӣ ба ин версия аз нав ворид шудан лозим мешавад.
- `/api` танҳо дархостҳоро аз `REGISTRY_CORS_ORIGINS` қабул мекунад. Дар истеҳсол арзиши он бояд origin-и HTTPS бошад, масалан `https://registry.example.tj`.
- Дар муҳити истеҳсол `APP_ENV=production`, `REGISTRY_ADMIN_CODE`, `REGISTRY_ADMIN_PASSWORD` (на кам аз 16 аломат) ва `REGISTRY_CORS_ORIGINS` ҳатмианд. Сиррҳоро ҳамчун secret-и платформа таъин кунед; ба git ё `NEXT_PUBLIC_*` нагузоред.
- Барои фронтенд ҳангоми сохтан `NEXT_PUBLIC_API_BASE=https://api.example.tj/api` таъин кунед. Ин URL-и оммавии API аст, на API key.
- HTTPS-ро дар reverse proxy/load balancer бо сертификати эътиборнок фаъол кунед, портҳои дохилии Uvicorn-ро аз интернет пӯшед ва proxy-ро ба HTTPS origin фронтенд ва API маҳдуд кунед. Барномаи FastAPI худ сертификати TLS намедиҳад. Дар истеҳсол Uvicorn-ро бе `--reload` оғоз кунед.
- Файли база ва нусхаҳои эҳтиётиро берун аз web root, бо ACL-и маҳдуд ба ҳисоби хидматрасон нигоҳ доред. Агар API-ро дар чанд worker/server кор фармоед, маҳдудияти суръати дохили равандро бо rate limit-и reverse proxy/WAF иваз ё пурра кунед.
- API дархостҳои тағйирдиҳандаро бо `Origin` месанҷад; барои ҷаласаҳои cookie ин муҳофизати CSRF аст. Ҷавобҳо ва сайт сарлавҳаҳои амниятӣ доранд; матн дар React бе `dangerouslySetInnerHTML` нишон дода мешавад ва URL-ҳои медиа/пайванд дар backend санҷида мешаванд.
- Пардохт ё қабули маблағ дар ин backend вуҷуд надорад; агар илова шавад, маблағ ва ҳолати пардохтро танҳо сервер бояд аз провайдер тасдиқ кунад.

## Оғоз

Аз ҷузвдони асосии лоиҳа фармонро иҷро кунед, то роҳи `backend.app:app` дуруст ҳал шавад:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt
```

Пеш аз оғоз маълумоти беназири администраторро дар муҳити ҳамин равзанаи PowerShell таъин кунед. Парол бояд на кам аз 12 аломат бошад; онро ба код ё файли лоиҳа нанависед:

```powershell
$env:REGISTRY_ADMIN_CODE = "GOS-ADMIN"
$securePassword = Read-Host "Пароли нави администратор" -AsSecureString
$env:REGISTRY_ADMIN_PASSWORD = (New-Object System.Net.NetworkCredential("", $securePassword)).Password
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Дар сервери истеҳсолӣ ин арзишҳоро ҳамчун secret/environment variables-и платформа таъин кунед. Агар ҳисоби кӯҳнаи пешфарзии `GOS-ADMIN` / `admin123` ёфт шавад, он худкор ғайрифаъол мешавад; ҳисоби маъмурӣ бо танзимоти муҳит сохта ё нав карда мешавад.
