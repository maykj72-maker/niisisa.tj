# Сертификатҳо ва меъморӣ

## Сохтори лоиҳа

```text
backend/
  app.py                 API, моделҳои дархост, пойгоҳи SQLite ва роҳҳо
  registry.db            маълумоти маҳаллии SQLite
  uploads/               аксҳо ва видеоҳои боркардаи администратор
  requirements.txt       бастаҳои Python
frontend/
  app/
    page.tsx             феҳристи сертификатҳо ва кабинетҳо
    architecture/        портали пажӯҳишгоҳ, хабарҳо ва идоракунии муҳтаво
    news/                рӯйхати хабарҳо ва саҳифаи ҳар хабар
  public/                логотип ва аксҳои сомона
  package.json           вобастагиҳо ва фармонҳои Next.js
```

Аввал `backend/app.py`-ро бинед, то API ва ҷадвалҳои додаҳоро фаҳмед. Баъд дар `frontend/app/page.tsx` равиши феҳрист, дар `frontend/app/architecture/` саҳифаи пажӯҳишгоҳ ва дар `frontend/app/news/` саҳифаҳои хабарҳоро омӯзед. Тарҳи нав аз мундариҷа ҷудо буда, дар `frontend/app/architecture/modern-theme.css` ҷойгир аст.

Лоиҳа аз ду бахши ба ҳам пайваст иборат аст:

- `/` — феҳристи сертификатҳо, сабти довталабон ва панели идоракунӣ.
- `/architecture` — портали иттилоотии пажӯҳишгоҳ бо забонҳои тоҷикӣ ва русӣ, самтҳои фаъолият ва хизматрасониҳо.
- `/services` — каталоги хизматрасониҳо ва дархостҳо: довталаб дархостҳои худро мефиристад ва пайгирӣ мекунад, администратор ҳамаи дархостҳоро баррасӣ мекунад.
- `/documents` — китобхонаи ҳуҷҷатҳои оммавӣ. Ҳама метавонанд ҳуҷҷатро бинанд ва боргирӣ кунанд; илова, таҳрир ва несткунӣ танҳо барои администратор дастрас аст.

Ҳар ду саҳифа ба ҳам пайванд доранд. Портали меъморӣ инчунин ба саҳифаи расмии Кумитаи меъморӣ ва сохтмони Тоҷикистон пайванд медиҳад.

Администратор метавонад хабарҳоро дар `/news` илова, таҳрир ва нест кунад. Ҳабарҳои нашршуда дар портали меъморӣ ва рӯйхати `/news` намоиш дода мешаванд. Барои ҳар хабар тугмаи «Муфассал» матни дарозро мекушояд ва сарлавҳа саҳифаи ҷудогонаи `/news/{id}`-ро мекушояд.

Дар `/architecture` забонро бо тугмаҳои TJ/RU иваз кардан мумкин аст. Администратори воридшуда муҳтавои ҳар забонро ҷудогона идора мекунад: матнҳо ва сарлавҳаҳо, роҳбарон, самтҳо, хизматрасониҳо, маълумоти тамос, рӯйхатҳо ва аксҳо. Элементҳоро илова, таҳрир, нест ва аз нав тартиб дода, баъд бо «Сабт ва нашр» тағйиротро сабт мекунад. Ахбор низ матни тоҷикӣ ва русии алоҳида дорад. Муҳтавои CMS дар SQLite нигоҳ дошта мешавад; тағйир додани он танҳо барои администратор иҷозат аст.

Администратор метавонад барои аксҳо сарлавҳа ва тавсиф ворид кунад ва ба галереяҳо ё ахбор видеоҳои MP4/WebM бо садо илова намояд. Ҳаҷми максималии видео 100 МБ ва акс 5 МБ аст. Хабарҳои дар сомона кушодашуда шумораи хонандагони беномро нишон медиҳанд: браузер бо нишондиҳандаи тасодуфӣ ҳисоб мешавад, маълумоти шахсӣ нигоҳ дошта намешавад.

Дар `/documents` администратор метавонад санадҳои меъёрӣ, фармонҳо, маводи методӣ, бланкҳо ва ҳуҷҷатҳои дигарро бор кунад. Файлҳо дар захираи хусусии backend нигоҳ дошта шуда, тавассути API дастрас мешаванд; андозаи файл то 20 МБ маҳдуд аст. Дар `/services` довталаб метавонад хизматрасониро интихоб карда, дархост фиристад. Маъмур вазъро тағйир дода, эзоҳ илова мекунад; дархостҳои довталабон аз ҳамдигар ҷудо нигоҳ дошта мешаванд.

Довталаб дар саҳифаи асосӣ сабти ном карда, баъд бо рамз ва гузарвожаи худ ба кабинети шахсӣ медарояд. Дар кабинет ӯ метавонад маълумоти сертификатсияро фиристад ва танҳо дархостҳои худ, инчунин вазъи баррасии онҳоро бинад. Дархостҳои нав ба рӯйхати маъмур мераванд ва то тасдиқ дар ҳолати баррасӣ мемонанд. Маъмур метавонад маълумотро таҳрир, тасдиқ, бекор ё нест кунад; довталаб баъд аз нав кардани вазъ натиҷаро мебинад.

Барои ҳар сабт рақами бақайдгирӣ ва QR-и доимӣ дода мешавад. Администратор метавонад ҳангоми сабти сертификат рақамро дастӣ ворид кунад; агар майдон холӣ бошад, рақами ягона ба таври худкор сохта мешавад. Рақам ҳангоми таҳрири сертификат иваз намешавад ва рақами дастӣ низ барои тавлиди рақамҳои автоматӣ ба ҳисоб гирифта мешавад. PDF-и умумӣ барои сабтҳои филтршуда ва PDF-и алоҳидаи ҳар сертификат ҳамаи майдонҳои маълумотро дар бар мегиранд. Скан кардани QR ҳолат ва маълумоти санҷиши сертификати нашршударо нишон медиҳад.

Феҳрист бо 25 сабт дар ҳар саҳифа бор мешавад; ҷустуҷӯ аз рӯи ФИО ё рақами бақайдгирӣ ва филтри вазъ дар сервер иҷро мешаванд. Экспорт ҳамаи сабтҳои мувофиқи ҷустуҷӯ ва филтрро мегирад, на танҳо саҳифаи кушода. API-и `/api/certificates` параметрҳои `search`, `status`, `offset` ва `limit`-ро дастгирӣ мекунад (`limit` то 200); дархости бе ин параметрҳо шакли пешинаи рӯйхатро бармегардонад.

## Оғози кор

Дар терминали якум сервери API-ро оғоз кунед:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt
python -m uvicorn backend.app:app --reload --host 127.0.0.1 --port 8000
```

Дар терминали дуюм, аз ҷузвдони `frontend`, интерфейсро оғоз кунед:

```powershell
cd frontend
npm install
npm run dev
```

Сомона дар [http://localhost:3000](http://localhost:3000) дастрас мешавад. URL-и API-ро бо тағйирёбандаи `NEXT_PUBLIC_API_BASE` иваз кардан мумкин аст; арзиши пешфарз `http://localhost:8000/api` аст.

Пеш аз оғоз кардани API, маълумоти администраторро дар муҳити сервер танзим кунед: `REGISTRY_ADMIN_CODE` ва `REGISTRY_ADMIN_PASSWORD` (гузарвожа бояд на камтар аз 12 аломат бошад). Маълумоти воқеии воридшавиро ба файлҳои версиядор ё ба танзимоти пешфарзи фронтенд нагузоред. API-и маҳаллӣ танҳо дар `127.0.0.1` гӯш мекунад; ҳангоми нашри беруна онро пушти proxy-и HTTPS ҷойгир кунед.

Барои санҷиши фронтенд (аз терминали дигар дар `frontend`):

```powershell
npm run lint
npm run build
```
